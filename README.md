# SpeakUp — робот-учитель английского (iPhone)

Сайт: https://sergeyned56-netizen.github.io/speakup/
На iPhone открыть в Safari → «Поделиться» → «На экран «Домой»».

## Что умеет
- Голосовой разговор в реальном времени с роботом. 3 характера: Cheeky / Kind / Strict coach.
- Исправляет ошибки вслух. Ошибки попадают в **Notebook** и возвращаются через 1, 3, 7 и 14 дней, пока не скажешь правильно; после этого считаются выученными.
- **Missions**: ролевые игры с целью (снять квартиру, граница, собеседование, возврат товара и др.), в конце вердикт.
- **Отчёт после разговора**: уровень, главные ошибки, «как сказал бы носитель», новые фразы (сами попадают в Notebook), домашка.
- **Карточки слов** (Notebook → Words): слово, транскрипция, объяснение на простом английском, примеры, синонимы, озвучка 🔊. Повторяются по тем же интервалам. Своё слово можно добавить вручную: карточку сделает дешёвая модель примерно за $0.0001.
- **Память**: робот запоминает факты о тебе из отчётов. Посмотреть и удалить их можно во вкладке Progress.
- **Progress**: серия дней, минуты, доля твоей речи, ошибки в минуту, уровень, расходы за месяц.

## Экономия
- По умолчанию стоит `gpt-realtime-mini`, примерно в 3 раза дешевле полной модели.
- Длина ответов робота настраивается: Normal или Short (дешевле). Старый контекст обрезается.
- Счётчик $ виден прямо в разговоре, лимит за сессию задаётся в Settings.
- Автостоп, если молчишь (по умолчанию 45 с) или свернул приложение.

## Как обновить сайт
github.com/sergeyned56-netizen/speakup → **Add file → Upload files** → перетащить изменённые файлы → **Commit changes**. Через 1–2 минуты закрыть и заново открыть приложение на телефоне.

## Файлы
- `tutor.js` — поведение робота (характеры, исправления, повторение)
- `topics.js` — темы и миссии
- `report.js` — отчёт после разговора
- `store.js` — блокнот, повторение, статистика, память
- `robot.js` — внешний вид робота
- `realtime.js` — связь с OpenAI и подсчёт стоимости
- `app.js`, `index.html`, `style.css` — экраны
