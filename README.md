# SpeakUp — голосовой собеседник для прокачки английского (iPhone)

Говоришь голосом в реальном времени с милым роботом-учителем (по умолчанию его зовут Bolt). Он моргает, двигает ртом, когда говорит, и пугается, когда ты ошибся. Ошибки сразу поправляет вслух, а приложение сохраняет их в журнал «Мои ошибки». Тема «🔁 Разбор моих ошибок» прогоняет тебя по ним ещё раз.

Характер выбирается в настройках: 😏 дерзкий (подкалывает), 🥰 добрый или 💪 строгий тренер. Не знаешь, о чём говорить? Жми «🎲 Удиви меня» или 🔀 прямо во время разговора.

Это веб-приложение: открываешь ссылку в Safari и добавляешь на экран «Домой». После этого оно запускается с иконки, как обычное приложение, без App Store и без перепрошивок. Второму человеку достаточно прислать ссылку.

## Шаг 1. Выложить в интернет (один раз, ~5 минут)

Нужен HTTPS, иначе iPhone не даст доступ к микрофону. Проще всего через бесплатный GitHub Pages:

1. На github.com создай **публичный** репозиторий `speakup` (Pages на бесплатном тарифе работает только с публичными; ключа в коде нет, так что это безопасно).
2. В Терминале на Маке:
   ```bash
   cd ~/Desktop/speakup
   git init && git add . && git commit -m "SpeakUp"
   git branch -M main
   git remote add origin https://github.com/<твой-ник>/speakup.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Через минуту во вкладке **Actions** появится ссылка вида `https://<твой-ник>.github.io/speakup/`.

После каждого `git push` сайт обновляется сам.

*Вариант:* можно просто скопировать папку `www` на свой сервер с доменом и HTTPS. Подойдёт тот же, где живёт киношка.

## Шаг 2. Поставить на iPhone

1. Открой ссылку **в Safari**.
2. **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → Добавить.
3. Запусти SpeakUp с иконки → **Настройки** → вставь OpenAI API ключ.
4. При первом разговоре разреши доступ к микрофону.

## Что нужно

- **OpenAI API ключ** (platform.openai.com → API keys) с пополненным балансом. Подписка ChatGPT не подходит.
- **VPN**, если находишься в России: OpenAI не работает с российских IP.
- Стоимость: `gpt-realtime` примерно $0.1–0.3 за минуту, `gpt-realtime-mini` в несколько раз дешевле (переключается в настройках).

## Файлы

- `www/tutor.js` — характеры робота и то, как он исправляет и ведёт разговор. **Главное место для настройки.**
- `www/robot.js` — внешний вид и анимации робота.
- `www/topics.js` — темы.
- `www/realtime.js` — подключение к OpenAI Realtime.
- `www/app.js` — экраны, журнал ошибок.
- Ключ и журнал ошибок хранятся только на телефоне.
